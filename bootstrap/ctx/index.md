# Project context

Read `rules/workflow.md` before substantive work; use the ticket skill to establish a ticket.

- Tickets: `tickets/index.md` — compact shared ledger; each ticket holds its own checkpoint.
- Research: `research/index.md` — retained evidence and conclusions, read by relevance.
- Memory: `memory/index.md` — durable verified knowledge, read by relevance.
- Local: `local/` — ignored machine/private data; never preload or summarize into shared files.

Use the ticket ID in the current session as its active pointer. Multiple sessions may work on
different tickets; there is no project-wide singleton active ticket. Open the selected ticket
to resume. Unknown private work must stay private until its visibility is clarified.
