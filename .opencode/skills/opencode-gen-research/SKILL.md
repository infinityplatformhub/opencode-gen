# Research procedure

Establish a ticket via `opencode-gen-ticket` before research. Follow `.ctx/rules/workflow.md`.
Search relevant research indexes before repeating work. Set the question, scope, and decision
the research must support. Put experiments and transient output in `.ctx/local/tmp/`.

Retain findings only when useful beyond the immediate turn. Shared research goes in
`.ctx/research/`; confidential findings in `.ctx/local/research/` with a private index.
Record date, question, sources/evidence, findings, uncertainty, conclusion, and ticket ID.
Keep one concise index link and one ticket reference; do not duplicate the research prose.
Split documents before the 12 KiB limit. Follow existing project docs when the result belongs
there instead. Load the memory skill only when a finding is verified and useful for future work.
Never move private findings to shared storage without explicit consent.
